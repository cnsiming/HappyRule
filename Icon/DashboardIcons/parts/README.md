# Dashboard Icons 按需分组

日常先用 [HappyRule 常用库](../../README.md)。需要其他图标时，先在 [官方查询页面](https://dashboardicons.com/icons) 找到名称，再按首字母与名称范围，只添加需要的一个分组。

共 40 组，覆盖全部 4,894 项，每组最多 200 项。不必同时添加所有组；原完整库继续保留作备用。分组降低单次列表与图片加载量，手机实际速度仍取决于网络与 QX。

在 QX 中将已添加的完整图库条目移出图标库列表后，改用下列分组；操作对象是图标库列表，不是分流策略或配置文件。首次加载后保留图片缓存，日常无需反复清空缓存。
